# ثَبات THABAT v0.1

نسخة أولية لإثبات جدوى تحليل حركة الجزء العلوي عبر كاميرا الجوال باستخدام MediaPipe Pose Landmarker.

## ما الذي تعمل عليه النسخة الحالية؟
- تشغيل الكاميرا الأمامية.
- رسم Pose Skeleton لحظيًا.
- حساب زاوية الكتف الأيسر والأيمن.
- حساب فرق التماثل بين الذراعين.
- حساب تقدير مبسط لميل الجذع.
- توجيه نصي وصوتي أولي أثناء اختبار رفع الذراعين.

> مهم: الحدود المستخدمة للـfeedback تجريبية وليست clinical cutoffs، والنسخة ليست أداة تشخيص.

## تشغيلها على Windows
الكاميرا في المتصفح تحتاج `localhost` أو HTTPS. لا تفتحي `index.html` مباشرة بالنقر المزدوج.

1. افتحي المجلد في VS Code.
2. افتحي Terminal داخل المجلد.
3. شغلي أحد الخيارين:

### إذا كان Python مثبتًا
```bash
python -m http.server 8000
```
ثم افتحي:
`http://localhost:8000`

### أو استخدمي Live Server في VS Code
شغلي `index.html` عن طريق إضافة Live Server.

## الإنترنت
v0.1 تحتاج الإنترنت أول مرة/أثناء التشغيل لأنها تجلب MediaPipe WASM والنموذج من المصادر الرسمية عبر CDN. لاحقًا يمكن جعل الملفات محلية لنسخة شبه Offline.

## الاختبار الصحيح
1. ضعي الكاميرا أمامك بحيث يظهر الرأس، الكتفان، الذراعان والحوض.
2. اجلسي أو قفي باستقامة.
3. ارفعي الذراعين ببطء.
4. راقبي الزوايا والـfeedback.

## ما نبنيه في v0.2
- Calibration صوتي تلقائي لموضع الكاميرا.
- تسجيل محاولة كاملة بدل قراءة frame واحدة.
- أفضل زاوية يصل إليها المستخدم (Max ROM).
- متوسط symmetry خلال الحركة وليس في لحظة واحدة.
